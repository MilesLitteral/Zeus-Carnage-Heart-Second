There are no other EXEs. Associated filetypes include:
### Unknown:
.PAC
.PRG
.ALL


### Meshes:
* .TMD, file format as used by the Sony Playstation/gslib to store 3D object information.

### Textures:
* .TIM, a standard image file format for the Sony PlayStation. The file structure closely mimics the way textures are managed in the frame buffer by the GPU. TIM files are little endian-based.
* .CLU, Color Palette?

### Video/FMVs:
* .MOT, Video Format, typically paired with .MID audio

### Audio:
* .MID, standard MIDI Audio format

### Maps:
* .BIN, Contains map file data

### OKE data files
* .DAT

### Scenarios
* .SCE (NOT TO BE CONFUSED WITH Win32/64 SECTION_FLAGS)

### Misc
* .MSG, Ingame Text, especially of menus and some canned dialogue
* .TMP, Temporary Memory Buffer, typically associated with saving and loading data

As progress is made new categories will pop up as to what each file relates to
